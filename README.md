# KARSTA Scientific Geographic Sandbox Tumblr Themes

This repository contains three distinct Tumblr-ready custom HTML themes based on the KARSTA geographic archive design language.

Files:
- `karsta-tumblr-v1-native.html` — Tumblr-native variables for tags, captions, notes, and post types
- `karsta-tumblr-v2-elite-dashboard.html` — darker “elite dashboard” variant
- `karsta-tumblr-v3-advanced-sidebar.html` — advanced sidebar and nested metadata panel version

Installation:
1. Open your Tumblr theme editor.
2. Paste the contents of the selected file into Custom HTML.
3. Save and preview.
4. Adjust Tumblr variables like `{Title}`, `{Description}`, or custom links as needed.

Design notes:
- Dark scientific archive aesthetic
- Gold accent system for links and highlights
- Strong metadata ledger styling
- Responsive layout for desktop and mobile
- Light mode / dark mode toggle included
